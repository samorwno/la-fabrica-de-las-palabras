# La fábrica de las palabras

Recurso educativo interactivo y gamificado para **Lengua Castellana de 5°**. Trabaja los verbos, los adjetivos y los adverbios mediante un esquema conceptual con siete puntos de interés, retos, XP, insignias y medallas.

## Características

- Un único archivo `index.html` autónomo: no requiere instalación, servidor ni conexión a internet.
- Diseño responsive para móvil y escritorio.
- Sonidos generados con la Web Audio API (sin archivos externos).
- Siete módulos con explicación, ejemplos y reto de aplicación.
- Sistema de gamificación: 210 XP posibles, racha de aciertos, insignias y medallas de oro, plata y bronce.
- Pantalla final con resultados y opción de reinicio.

## Uso

Abre `index.html` en cualquier navegador moderno o visita la versión publicada:

https://samorwno.github.io/la-fabrica-de-las-palabras/
